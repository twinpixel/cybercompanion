# Regole Cyberpunk 2020 — estratti strutturati

Questi file sono l'estrazione in markdown dei PDF in [`doc/`](../), fatta per
essere **letta dal codice e da chi sviluppa**, non per essere giocata: i dati di
gioco veri e propri vivono in [`server/data/`](../../server/data/) come JSON, e
questi documenti sono la fonte da cui quei JSON sono stati derivati.

Quando un JSON e un documento qui divergono, **vince il documento**: e' la
trascrizione del manuale.

## Nota sulla terminologia

L'edizione italiana traduce sia le caratteristiche sia le abilita', e le
traduzioni **non** sono un calco dell'inglese: `Awareness/Notice` diventa
`Individuare`, `Interface` diventa `Hacking`, `System Knowledge` diventa `Uso
computer`, `Body` diventa `Costituzione`. L'app usa la terminologia italiana,
che e' quella stampata sulla scheda che i giocatori hanno in mano.

## Provenienza e uso

I PDF in `doc/` sono materiale di riferimento personale del proprietario del
repository, tenuto qui perche' l'app riproduce fedelmente la scheda ufficiale.
Cyberpunk 2020 e' opera di R. Talsorian Games; alcuni PDF sono compendi amatoriali
(`Full Metal Jacked`, la lista armi) e non materiale ufficiale. Il repository e'
privato: se dovesse diventare pubblico, questi file vanno rimossi.
